Graphs: BFS, DFS & shortest paths

Implicit graphs on grids, and Dijkstra with a heap.

Many problems are graphs in disguise: grids (cells are nodes), dependencies, payment routes, service call chains. Pick the traversal by the question:

QuestionTool
Is X reachable? How many groups?DFS / BFS with a visited set, or union-find
Fewest steps (unweighted)BFS (queue); first time you reach a node is the shortest
Cheapest path, non-negative weightsDijkstra with a min-heap
Order with dependencies / detect cyclesTopological sort (Kahn) as in the Terraform exercise
Python gotcha: the default recursion limit is about 1000 frames. Recursive DFS on a big grid or a long chain crashes with RecursionError. Use an explicit stack or deque.

Answer key

1. Count islands back ↑

Hint: Scan every cell. When you find unvisited land, count an island and flood-fill it with an explicit stack or deque (BFS) while marking cells in a visited set. Recursion would exceed Python’s default recursion limit on a 400x400 grid.

Reference solution:

def num_islands(grid):
    seen = set()
    count = 0
    rows = len(grid)
    for r in range(rows):
        for c in range(len(grid[r])):
            if grid[r][c] == '1' and (r, c) not in seen:
                count += 1
                seen.add((r, c))
                stack = [(r, c)]
                while stack:
                    y, x = stack.pop()
                    for ny, nx in ((y + 1, x), (y - 1, x), (y, x + 1), (y, x - 1)):
                        if 0 <= ny < rows and 0 <= nx < len(grid[ny]) and grid[ny][nx] == '1' and (ny, nx) not in seen:
                            seen.add((ny, nx))
                            stack.append((ny, nx))
    return count

Grid problems are graph problems with implicit edges. Use a visited set (or mutate a copy) and an explicit stack when the depth can be large. Union-find is the alternative when cells arrive incrementally.

2. Cheapest route (Dijkstra) back ↑

Hint: Build an adjacency dict. Use a min-heap of (cost_so_far, node). Pop the cheapest; skip it if you already have a better distance recorded; relax its neighbours. Stop early when you pop dst.

Reference solution:

import heapq
from collections import defaultdict

def cheapest_route(edges, src, dst):
    graph = defaultdict(list)
    for u, v, cost in edges:
        graph[u].append((v, cost))
    best = {src: 0}
    heap = [(0, 0, src)]  # (cost, tiebreak, node): the tiebreak keeps non-comparable node ids out of comparisons
    counter = 1
    while heap:
        cost, _, node = heapq.heappop(heap)
        if node == dst:
            return cost
        if cost > best.get(node, float('inf')):
            continue
        for nxt, w in graph[node]:
            new = cost + w
            if new < best.get(nxt, float('inf')):
                best[nxt] = new
                heapq.heappush(heap, (new, counter, nxt))
                counter += 1
    return None

Dijkstra needs non-negative weights; with negative edges use Bellman-Ford. The tiebreak counter avoids comparing node objects that may not be orderable. For a source-to-target query on a huge graph, mention bidirectional search and A*.

3. Quick check back ↑

B. BFS with a queue and a visited set

All steps cost the same, so BFS finds the shortest path in O(cells). Dijkstra also works but adds a log factor for no benefit. Recursive DFS over all paths is exponential and would overflow the stack.

4. Check 1 back ↑

C. Dijkstra with a min-heap, because edge weights are non-negative

BFS is for uniform cost; with non-negative weights Dijkstra with a heap gives the cheapest path.

5. Check 2 back ↑

A. Use an explicit stack or deque instead of recursion, since the default limit near 1000 frames crashes on deep grids

Deep recursive DFS overflows the call stack; an explicit stack visits the same nodes without that limit.
