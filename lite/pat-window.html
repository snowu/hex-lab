Sliding window & two pointers

Expand right, shrink left, keep an invariant. O(n) instead of O(n²).

When the question asks about a contiguous range, avoid recomputing from scratch for every start. Maintain a window [left, right] and a summary of what is inside (a sum, a set, a count dictionary).

left = 0
for right, x in enumerate(items):
    add(x)                     # expand
    while window_is_invalid():  # or: while window_is_valid() for "shortest"
        remove(items[left])     # shrink
        left += 1
    update_best(right - left + 1)
  • Fixed size k: slide by adding the new element and removing the one leaving.
  • Variable size: shrink only when the invariant breaks (longest) or while it holds (shortest).
  • Each pointer only moves forward, so the total work is O(n), even with a nested while.

Answer key

1. Longest substring without repeats back ↑

Hint: Keep a window [left, i] and a dict of the last index where each character was seen. When you meet a character already inside the window, jump left to one past its previous position. Never move left backwards ("tmmzuxt" catches that).

Reference solution:

def longest_unique(s):
    last = {}
    left = best = 0
    for i, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1
        last[ch] = i
        best = max(best, i - left + 1)
    return best

Variable-size sliding window: expand right every step, shrink left only when the invariant breaks. The classic bug is moving left backwards.

2. Shortest subarray with sum at least target back ↑

Hint: Grow the window on the right adding to a running sum. While the sum is at least target, record the length and shrink from the left. This works because every number is positive.

Reference solution:

def shortest_subarray(target, nums):
    best = 0
    left = total = 0
    for right, x in enumerate(nums):
        total += x
        while total >= target:
            length = right - left + 1
            best = length if best == 0 else min(best, length)
            total -= nums[left]
            left += 1
    return best

The window only works for non-negative numbers. With negatives the sum is no longer monotonic, and you need prefix sums plus a monotonic deque (or a heap).

3. Check 1 back ↑

A. Expand right and shrink only while the window holds more than K distinct characters, recording the best while valid

For longest-valid problems shrink only to restore the invariant; each pointer still moves forward once, giving O(n).

4. Check 2 back ↑

C. Each pointer moves forward at most n times, so total work is O(n) despite the nesting

Both pointers only advance, so the inner loop performs at most n shrinks across the whole run.
