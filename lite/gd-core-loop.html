Core loop, verbs and pillars

How to describe what a game actually is, so you can tell whether a feature belongs.

The core loop

The core loop is the smallest cycle the player repeats: do something → get a result → that changes what you do next. If this loop is not fun in isolation, no amount of content saves it. Examples:

  • Tetris: see piece → place it → clear lines (or stack higher) → see next piece.
  • Hades: enter room → fight → pick a reward → stronger next room. Around it sits a longer loop: die → return to the hub → spend meta currency → try again.
  • A farming sim: plant → wait → harvest → sell → buy better seeds.

Games stack loops at different timescales. A common frame is seconds (a single action, the feel), minutes (a fight, a level) and hours (progression, story). Each layer should give a reason to continue the next.

Verbs

List the player's verbs (jump, shoot, build, trade, hide). Good small games have a few verbs with depth rather than many shallow ones, and the interesting part is how verbs combine with the world (jump onto enemies, shoot to open doors). Before adding a feature, ask whether it adds a verb, deepens a verb, or only adds content.

Pillars

Design pillars are 3 or 4 short statements of what the game is, used to say no. “Fast, readable combat.” “Every run feels different.” “Cozy, never punishing.” A feature that fights a pillar gets cut, however cool it is. Write them on day one; they are the cheapest tool for keeping scope under control.

MDA: mechanics, dynamics, aesthetics

The MDA framework (Hunicke, LeBlanc, Zubek) separates what you build from what players experience:

  • Mechanics: rules and data you author (jump height, spawn rates).
  • Dynamics: behaviour that emerges when players interact with the rules (camping, rushing, hoarding).
  • Aesthetics: the emotional result (challenge, discovery, fellowship, expression, narrative, sensation...).

Designers work from mechanics upward, but players experience it from aesthetics downward. When a playtester says “this is boring” that is an aesthetics report, and the cause is several steps below it, in the rules.

Exercise: describe a game you love in verbs, loops and pillars

Pick one game and write, in five lines each:

  1. The 10-second loop (what the hands do).
  2. The 10-minute loop (what the brain plans).
  3. The 10-hour loop (what keeps you coming back).
  4. The verbs, and two ways they combine.
  5. Three pillars you would guess the designers used, and one feature that clearly would have violated them.

If you cannot name the pillars, the game may not have had any, which also tells you something.
