Heaps & binary search on the answer

k-way merging, and turning “minimise the maximum” into a search.

Heaps

heapq is a min-heap. For a max-heap push negated values. Use a heap when you repeatedly need “the smallest/largest remaining”: top-k (keep a heap of size k), merging k sorted streams, scheduling by earliest deadline, Dijkstra.

Binary search on the answer

If you can write a fast feasible(x) that is monotonic (false … false true … true), you can binary search x even though the input is not sorted. Typical wording: “smallest capacity / minimum rate / minimise the maximum”. Always set the search bounds explicitly (lowest possible, highest possible) and be careful with lo < hi and mid updates to avoid infinite loops.

Answer key

1. Merge k sorted lists back ↑

Hint: Push (value, list_index, position) for the first element of each non-empty list into a heap. Pop the smallest, append it, and push the next element from the same list. (heapq.merge exists, but be able to write it yourself.)

Reference solution:

import heapq

def merge_k_sorted(lists):
    heap = [(lst[0], i, 0) for i, lst in enumerate(lists) if lst]
    heapq.heapify(heap)
    out = []
    while heap:
        value, i, j = heapq.heappop(heap)
        out.append(value)
        if j + 1 < len(lists[i]):
            heapq.heappush(heap, (lists[i][j + 1], i, j + 1))
    return out

Same shape as merging sorted log shards or sorted result pages from several services. The heap holds k items, so each of the N pops costs O(log k).

2. Binary search on the answer back ↑

Hint: The answer lies between max(weights) and sum(weights), and feasibility is monotonic: if capacity C works, C+1 works. Binary search the capacity, with a greedy helper that counts the days needed for a given capacity.

Reference solution:

def min_capacity(weights, days):
    def days_needed(cap):
        used, load = 1, 0
        for w in weights:
            if load + w > cap:
                used += 1
                load = 0
            load += w
        return used

    lo, hi = max(weights), sum(weights)
    while lo < hi:
        mid = (lo + hi) // 2
        if days_needed(mid) <= days:
            hi = mid
        else:
            lo = mid + 1
    return lo

Recognise “minimise the maximum” or “smallest value that satisfies a monotonic check” as binary search on the answer space. The same trick sizes rate limits, worker counts and batch sizes.
