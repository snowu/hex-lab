# Native contract matrix

Manual review covers the public behaviors below for all 149 original ports (55 C, 54 C++, 40 Zig), across 70 exercises. All 417 bundles retain their instruction text and upstream provenance fields. Runtime regression evidence is in [native-contract-regressions.json](native-contract-regressions.json); source/test hashes and exact per-variant evidence are in [native-semantic-audit.json](native-semantic-audit.json).

Counts are static assertion sites, not exhaustive scenario counts: loop/table tests execute several cases at each site. Scalar domains follow each native header (for example uint16 square-root, uint32 VLQ, and int/i64 rational arithmetic). Ownership, caller buffer capacity, coordinate bases and error/status conventions are documented in the native APIs; these representations are reviewed alongside the Python instructions.
